# Hermes Agent 快速入门教程

Claude Code、Codex 这类终端 Agent 解决的是"在代码里干活"，但每次开新会话你都要重新解释一遍自己是谁、想要什么——人记住了，Agent 没记住。Hermes Agent 的核心卖点恰恰相反：**它会自己记住、自己沉淀、越用越懂你**。它由 Nous Research 于 2026 年 2 月开源（MIT 协议），口号是 "The agent that grows with you"（和你一起成长的 Agent）。这章不讲原理，只带你完成第一次对话，用 10 分钟亲身体验三件事：终端怎么用、模型怎么选、自进化是怎么发生的。

## 一、第一次对话

假设你已经装好了 Hermes（安装见《安装教程》），在终端直接输入：

```bash
hermes
```

如果看到的是纯命令行交互，可以加上 `--tui` 参数进入现代终端界面（官方推荐）：

```bash
hermes --tui
```

![Hermes 终端首次对话](/images/hermes/quick-start/01-first-conversation.png)

### 1.1 TUI 里能做什么

进入 TUI 后，你可以直接打字提问，不用管 Markdown、不用管格式，像和一个同事聊天一样：

```text
hermes ❯ 帮我写一个 Python 脚本，统计当前目录下所有 .md 文件的行数，输出到 report.txt
```

你会立刻看到 Hermes 开始工作：读文件、跑命令、给出结果。注意它的工具输出是**流式**的——它调用的终端命令、文件读写过程会实时滚动展示，你随时能看到它在干什么，而不是干等一个黑箱结果。

TUI 支持的几个常用交互能力：

| 能力 | 说明 |
| --- | --- |
| 多行编辑 | 输入长 prompt 时，按 `Enter` 换行（或用编辑器），写完再提交 |
| 斜杠命令补全 | 输入 `/` 会自动弹出可用命令，按 `Tab` 补全 |
| 历史记录 | 方向键上下来回翻看之前的输入 |
| 流式工具输出 | 工具调用结果实时滚动，可随时中断 |

### 1.2 中途修改想法的三个技巧

- 想让 Agent 先规划再动手：直接说"先给我一个方案，确认后再执行"。
- 想打断正在跑的长任务：按 `Ctrl+C` 中断，再补一句修正指令。
- 任务太长被打断想重来：用 `hermes --continue` 恢复上一次会话，接着聊。

::: tip 类比理解
TUI 就像你和一个"随时在线的实习生"对话：它听你说话、能自己动手、干到一半可以喊停重新对齐。多行编辑和斜杠补全只是让它听懂你、也让你看懂它的工具。

## 二、核心体验：选模型与配工具

### 2.1 用 `hermes model` 选择模型

Hermes 是**提供商无关**的：背后接哪个模型由你决定。输入：

```bash
hermes model
```

会进入一个选择界面，让你依次挑选**提供商**和**具体模型**。支持的提供商包括 Nous Portal、OpenRouter、Anthropic、OpenAI、DeepSeek 等 15+ 家，本地模型也行（详见《配置教程》）。

::: warning 模型上下文至少 64K
Hermes 的多步工具调用需要"工作记忆"来记住上下文，因此所选模型**必须支持至少 64K tokens 上下文**。用上下文太短的模型，长任务会中途"失忆"。本地运行时需设置 `--ctx-size 65536`。
:::

### 2.2 用 `hermes tools` 配置工具

Hermes 内置 40+（官方文档称 70+）工具，按**工具集（toolsets）**组织。输入：

```bash
hermes tools
```

可以看到并按需启用这些工具集：

| 工具集 | 用途 | 典型场景 |
| --- | --- | --- |
| `web` | 网页搜索与提取 | 查资料、抓页面内容 |
| `browser` | 浏览器自动化 | 点击、填表、截图 |
| `terminal` | 运行 shell 命令 | 跑脚本、装依赖 |
| `file` | 读写、搜索文件 | 改代码、批量处理 |
| `code_execution` | Python 代码执行（沙箱） | 跑数据分析、验证脚本 |
| `vision` | 视觉分析 | 看图理解 |
| `image_gen` | 图像生成 | 配图、设计稿 |
| `delegation` | 任务委派子代理 | 并行处理多任务 |
| `cronjob` | 定时任务 | 定时自动执行 |
| `memory` | 读写记忆 | 沉淀长期信息 |

建议：刚开始全开默认工具集就行，跑通了再按需裁剪，避免权限弹窗过多。

## 三、自进化初体验：Agent 会自动沉淀技能与记忆

这是 Hermes 与普通终端 Agent 最大的不同，也值得你第一次对话就留意。当你让 Hermes 完成一个稍复杂、可能有固定套路任务（比如"按统一格式生成周报"）后，它会**在后台自动做两件事**：

1. **沉淀技能（Skills）**：把"怎么做"的步骤写成一份 `SKILL.md`，下次再遇到类似任务，它直接复用这套流程，不用你重新教。
2. **写入记忆（Memory）**：把你这个人的偏好、项目的事实存下来，跨会话持续增长。

![Hermes 自进化学习闭环](/images/hermes/quick-start/02-learning-loop.png)

### 3.1 怎么看到这些沉淀

在会话中输入斜杠命令即可查看：

```text
/skills     # 查看 Agent 已经学会的技能
/memory     # 查看 Agent 记住的事实
```

记忆文件默认存放在 `~/.hermes/memories/`，技能在 `~/.hermes/skills/`。你可以像翻阅笔记本一样直接打开这些文件，改掉不合适的条目。

### 3.2 一次验证自进化的具体做法

```text
hermes ❯ 以后帮我生成发布说明时，标题用英文，正文用中文，格式固定为：
hermes ❯ ## Summary / ## Changes / ## Notes 三段
```

下一次再说"生成今天的发布说明"，它就会自动套用你教的格式——这就是"和你一起成长的 Agent"的含义。

::: tip 记忆与技能的区别
一句话：**记忆是"事实"，技能是"怎么做"**。记忆存"用户喜欢中文正文"这类偏好，技能存"发布说明要分三段这样写"这类流程。两者配合，Hermes 才像真正记住了你的工作习惯。

## 四、两个入口：TUI vs 消息网关

Hermes 不是只能在终端里用。同一套 Agent，你随时可以在**两个入口**之间切换：

| 入口 | 启动方式 | 适合场景 |
| --- | --- | --- |
| TUI | `hermes` | 深度任务、编码、需要看工具输出的场景 |
| 消息网关 | `hermes gateway` | 把 Agent 放到 Telegram / Discord 等，手机上也能用 |

消息网关支持 Telegram、Discord、Slack、WhatsApp、Signal、email 等 **22 个平台/版本**。第一次上手时可以简单理解：**TUI 是"当面干活"，网关是"把它放在消息 App 里，随时吩咐"**。

## 五、常用命令速查表

| 命令 | 作用 |
| --- | --- |
| `hermes` | 进入交互式 TUI，开始对话 |
| `hermes --tui` | 显式使用现代终端界面 |
| `hermes --continue` | 恢复上次会话，断点续传 |
| `hermes chat -q "..."` | 一次性（one-shot）对话，适合脚本 |
| `hermes model` | 选择 LLM 提供商和模型 |
| `hermes tools` | 配置启用的工具 |
| `hermes config set <key> <value>` | 设置单个配置项 |
| `hermes gateway` | 启动消息网关 |
| `hermes setup` | 完整设置向导 |
| `hermes doctor` | 诊断问题 |
| `hermes update` | 更新到最新版 |
| `hermes profile create <name>` | 创建新的独立 Agent 实例 |
| `hermes claw migrate` | 从 OpenClaw 迁移配置过来 |

会话内常用斜杠命令：

| 斜杠命令 | 作用 |
| --- | --- |
| `/model <name>` | 会话内直接切换模型 |
| `/memory` | 查看 / 编辑记忆 |
| `/skills` | 查看 / 管理技能 |
| `/cron` | 创建定时任务 |
| `/background <prompt>` | 把任务丢到后台执行 |
| `/help` | 查看帮助 |
