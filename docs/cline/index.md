# Cline 快速上手

Cline 是一个开源 AI 编码代理，将前沿 AI 模型直接集成到你的 IDE 中。与普通的自动完成工具不同，Cline 是一个真正的编码代理——能理解整个代码库、规划复杂变更、执行多步骤任务。

**许可证**：Apache 2.0 | **GitHub**：⭐ 66k+（[cline/cline](https://github.com/cline/cline)）| **支持形式**：VS Code 扩展 · JetBrains 插件 · CLI · SDK

## 支持平台

- VS Code / Cursor
- JetBrains IDEs（IntelliJ、PyCharm、WebStorm 等）
- VSCodium / Windsurf

## 核心特点

| 特点 | 说明 |
|------|------|
| 完全透明 | 所有操作可见，完全可控 |
| 多模型支持 | Anthropic、OpenAI、Google、本地模型等 |
| 差异编辑 | 精确的代码变更，类似 Git diff |
| MCP 服务器 | 支持自定义工具扩展 |
| 上下文管理 | 自动压缩、焦点链、智能截断 |
| Cline 规则 | 定义项目级别的行为约定 |
