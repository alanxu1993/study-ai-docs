# 五、Cline 核心功能特性

## Plan / Act 双模式（核心工作流）

Cline 的标志性设计是"先想后做"的 **think-then-do** 工作流：

**Plan 模式（规划）**
- 只读探索代码库，提出详细行动方案
- 拆解任务、讨论方案，不执行任何修改
- 工具权限受限，只会提出"切换到执行模式"的建议
- 比执行模式便宜得多——规划阶段发现问题比执行完再返工省成本

**Act 模式（执行）**
- 完全执行：写文件、跑命令、用浏览器、调 MCP 工具
- 每个文件编辑和终端命令默认都需要你批准
- 也可以开启自动审批（auto-approve），让 Cline 自主运行

典型流程：**Plan 模式出方案 → 确认 → 切到 Act 模式执行 → 审查 diff**。方案获批后切到 Act 模式，Cline 会自动收到"用户已批准切换到执行模式，继续执行既定方案"的指令。

## 检查点与一键撤销

- 每次变更自动保存检查点快照
- 对任意历史版本**一键还原**
- 所有修改以 diff 形式展示，可审查、可修改、可回退

## 终端执行

- 直接在 VS Code 终端执行命令，实时观察输出
- 安装依赖、运行构建、执行测试、部署应用、管理数据库
- 对长驻进程（如 dev server）持续观察，捕获编译错误、测试失败、服务崩溃

## 智能编辑

- 跨文件协调修改，理解文件之间的关系
- **差异编辑**：类似 Git diff 的精确变更，不重写整文件
- **linter 感知**：边改边盯编译器和 linter 报错，自动修复缺失导入、类型错误、语法问题

## Focus Chain（焦点链）

焦点链通过自动维护的任务待办列表确保任务连续性：

- 任务开始时自动生成可操作步骤
- 随着工作进展实时更新
- 自动压缩后关键上下文仍然可见
- 无需滚动整个对话历史即可跟踪进度

## Auto Compact（自动压缩）

当上下文使用率达到约 80% 时自动触发：

- 自动创建对话的全面摘要
- 保留所有已做出的决策和代码更改
- 释放空间以继续工作
- 用户看到通知时任务已无缝继续

## 上下文截断系统

如果对话在自动压缩运行前就接近窗口限制，系统自动裁剪：

**优先保留：**
- 原始任务描述
- 最近的工具执行和结果
- 当前代码状态和活动错误
- 用户与助手的逻辑对话流

**优先删除：**
- 早期多余的对话历史
- 不再相关的已完成工具输出
- 中间的调试步骤
- 已完成目的的冗长解释

## @提及功能

通过 @符号引用上下文：

- `@file`：引用特定文件
- `@folder`：引用整个文件夹
- `@url`：引用在线文档
- `@git`：引用 Git 历史和变更
- `@problems`：引用项目中的错误和问题

## Cline 规则（.clinerules）

定义项目级别的行为约定，随仓库分发、自动生效：

- 代码风格规范
- 技术栈约束
- 命名约定
- 测试要求
- 安全规则
- 部署流程

还可配合 **Skills** 让模型在需要时加载特定规则。

## 记忆库

存储持久的项目知识和约定，跨会话保持：

- 项目架构说明
- 常用模式和约定
- 团队开发规范
- 技术债务清单

## MCP 服务器

通过 Model Context Protocol 扩展 Cline 的能力：

- **MCP 市场**：内置市场，按 GitHub 星标排序，一键安装常用服务器
- 连接外部 API、使用专有工具、访问企业数据源
- 集成自定义工作流
- 也可以让 Cline 现场为你创建自定义工具

## 浏览器控制

- 自动打开浏览器执行网页任务
- 调试前端 UI、抓取数据、填写表单、测试 Web 应用

## 多代理团队

协调多个 Agent 协作完成复杂任务：

- 协调者 Agent 把任务拆解给专职子代理，各自拥有独立工具和上下文
- 团队状态跨会话持久化，随时续作
- 示例：`cline --team-name auth-sprint "规划并用测试实现用户认证"`

## 定时 Agent（Scheduled Agents）

按 cron 计划运行自动化：

- 每日 PR 摘要、每周依赖检查、代码库健康报告
- 计划跨重启持久化，独立于终端会话运行
- 示例：`cline schedule create "PR summary" --cron "0 9 * * MON-FRI" --prompt "..."`

## 消息平台接入

把 Agent 连到任意消息平台：Telegram、Slack、Discord、WhatsApp、Google Chat、Linear

- 每个会话线程对应一个完整的 Agent 会话
- 可配置访问控制，限制谁能与你的 Agent 交互
