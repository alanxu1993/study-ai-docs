# 一、Cline 介绍

## 什么是 Cline

Cline 是一个开源 AI 编码代理，不同于传统的代码补全工具。它能够：

- 主动理解你的整个代码库结构
- 规划复杂的多步骤编程任务
- 在终端中执行命令并读取输出
- 创建、编辑、删除文件和目录
- 调用浏览器和外部 API
- 监控编译器和 linter 错误，边改边修

Cline 原名 **Claude Dev**，2024 年改名为 Cline。它是该领域最早的开源自主编码代理之一，拥有 65k+ GitHub 星标与数百万安装量，许可证为 Apache 2.0，完全开源、无厂商锁定。

## 与代码补全工具的区别

| 特性 | 代码补全工具 | Cline |
|------|-------------|-------|
| 上下文范围 | 当前文件 | 整个代码库 |
| 任务复杂度 | 单行/函数补全 | 多文件、多步骤 |
| 文件操作 | 仅建议 | 读写创建删除 |
| 终端执行 | 不支持 | 支持 |
| 外部工具 | 不支持 | 支持 MCP |
| 项目理解 | 无 | 持续构建上下文 |

## 产品形态

Cline 不是单一形态，而是同一引擎驱动的全家桶：

| 形态 | 说明 |
|------|------|
| **VS Code 扩展** | 编辑器内完成编码、跑命令、浏览网页，人工审批每个动作 |
| **JetBrains 插件** | IntelliJ / PyCharm / WebStorm 等同一体验 |
| **CLI** | `npm i -g cline`，终端交互或完全无人值守，用于 CI/CD |
| **Kanban** | 网页版多代理任务看板，每张卡片独立工作树、自动提交 |
| **SDK** | `npm install @cline/sdk`，用同一引擎构建自己的 Agent |

## Cline 的工作方式

Cline 在对话中持续构建对项目的理解，这叫做"上下文管理"。它将以下信息整合在一起：

1. **即时上下文**：当前对话和活动文件
2. **项目上下文**：代码库结构、模式和约定
3. **持久上下文**：记忆库、Cline 规则和文档

## 核心功能一览

- **Plan / Act 双模式**：先规划、后执行，人始终掌控哪些变更落地
- **Focus Chain（焦点链）**：自动维护任务待办列表，保持任务连续性
- **Auto Compact（自动压缩）**：上下文接近上限时自动生成摘要
- **上下文截断**：智能裁剪旧对话，保留关键信息
- **@提及**：引用特定文件、文件夹或 URL
- **记忆库**：存储持久的项目知识和约定
- **MCP 服务器**：通过 Model Context Protocol 扩展能力
- **.clinerules 规则**：定义项目级别的行为约定
- **检查点（Checkpoint）**：随时一键撤销 Agent 的修改
- **多代理团队**：协调者拆解任务，委派给专职子代理

## 使用成本

- 基础使用完全免费（开源 + BYOK，自带 API Key）
- 可选订阅 **ClinePass**（约 $9.99/月）解锁更多功能与模型额度
- 团队版约 $20/用户/月（前 10 个席位免费），支持集中计费与 SSO
