# 五、主要类型与应用场景

根据复杂度和自主性，AI Agent 可以分为不同类型，应用于各种场景。

## 5.1 四大类型

![幽灵站在四扇门前挑选：单一任务、多模态、自主、模拟](/images/ai-agent/types/01-four-types.png)

| 类型 | 特点 | 应用场景举例 |
|------|------|-------------|
| **单一任务 Agent** | 专注于完成一件特定事情，功能专一 | 智能客服机器人、自动数据录入助手、个人日程提醒助手 |
| **多模态 Agent** | 理解和处理文本、图像、语音等多种信息 | 根据草图生成网站代码、分析医学影像并生成报告、视频内容自动摘要 |
| **自主 Agent** | 拥有较高自主性，可长期运行并主动管理复杂目标 | 自动驾驶汽车、自动化股票交易系统、智能游戏 NPC |
| **模拟 Agent** | 在虚拟环境中进行模拟、测试和训练 | 训练机器人完成抓取任务、模拟城市交通流量优化、新药研发的分子模拟 |

::: tip 类型不是排他
同一个 Agent 可以同时是"多模态"和"自主"的。类型描述的只是它的**主要取向**：这扇门你最常用，不代表其他门是空的。选型思路——需求单一选单一任务，信息类型复杂选多模态，需要长期无人值守选自主，要测试训练选模拟。
:::

## 5.2 当前热门的实际应用

### 🤖 AI 编程助手

如 **Devin**，能独立完成从需求分析、写代码到测试部署的全流程。

![幽灵推着小推车走过需求、方案、编码、测试、部署五站](/images/ai-agent/types/02-coding-agent.png)

```
需求分析 → 技术方案 → 编码实现 → 测试 → 部署
   └─────────── AI 编程助手全流程 ────────────┘
```

::: info 2026 编程助手三分天下
- **Cursor**：IDE 原生路线，全仓库索引 + 多文件联动编辑，月活开发者破 500 万
- **Devin**：全自主沙箱路线，可独立工作数小时到数天，签下多家 Fortune 500 年度合同
- **Claude Code**：终端原生路线，200K 上下文，工具调用强，在 SWE-bench Verified 达到约 80.8%

真实案例：Bun 创始人用约 50 套动态工作流指挥 64 个 Claude 实例并行，11 天完成 53 万行代码的跨语言迁移；Devin 已承担 Cognition 公司约 25% 的内部 PR。
:::

## 5.3 各类型的发展趋势

```
单一任务 Agent ──→ 多模态 Agent ──→ 自主 Agent
      │                  │                │
      ▼                  ▼                ▼
  功能专一           多感官融合        长时间自主
  精准高效           综合理解          复杂决策
```

::: tip 如何选择合适的 Agent 类型？

- 有明确单一需求 → **单一任务 Agent**（如智能客服）
- 涉及多种信息类型 → **多模态 Agent**（如医疗诊断）
- 需要长期自主运行 → **自主 Agent**（如量化交易）
- 需要模拟测试 → **模拟 Agent**（如自动驾驶训练）
:::
