# Kilo Code 快速上手

Kilo Code 是一个开源 AI 编程助手，支持在 IDE、终端、浏览器和移动端使用。它可以生成代码、自动审查、调试问题，并以理解代码库的方式帮助你更快地交付。

**许可证**：MIT | **GitHub**：⭐ 27k+（[Kilo-Org/kilocode](https://github.com/Kilo-Org/kilocode)）| **模型**：500+ 种零加价调用

## 使用场景

| 平台 | 说明 |
|------|------|
| VS Code / JetBrains | IDE 深度集成 |
| CLI | 终端脚本和自动化 |
| 浏览器 & 移动端 | iOS / Android 应用 |
| Slack | 工作区中直接对话 |

会话在所有平台间同步——你可以在手机上开始一个任务，在 IDE 中完成它。

## 核心能力

| 能力 | 说明 |
|------|------|
| AI 编码 | 对话式生成、重构和调试代码 |
| 协作 | 共享会话、管理团队设置、追踪 AI 使用 |
| 自动化 | AI 代码审查、自动修复、基于 Issue 创建 PR |
| 部署与安全 | 直接部署应用、运行安全扫描 |
