# 一、Kilo Code 介绍

## 什么是 Kilo Code

Kilo Code 是一个开源 AI 编码助手，作为 AI 配对程序员在你的 IDE、终端、浏览器中工作。它支持多平台、多模式，并提供团队协作和自动化能力。

它是完全开源的（MIT 许可证），提供 **500+ 种 AI 模型** 按提供商原价调用、零加价，无需 API Key 即可开始体验。

## 背景与团队

Kilo Code 是 Cline 和 Roo Code 的直接分支，并在 2025 年 12 月获得 **800 万美元种子融资**，联合创始人之一是 GitLab 联合创始人 Sid Sijbrandij。其 CLI 部分则源于对 [OpenCode](https://opencode.ai) 的增强。Kilo 团队持续从 Cline、Roo 等开源项目合并优秀特性，同时构建自己的愿景，目标是成为"一体化 Agentic 工程平台"。

## 核心理念

Kilo Code 的目标是成为**全平台的 AI 开发伙伴**：

- 不局限于单一 IDE
- 支持命令行脚本和自动化
- 提供移动端访问
- 内置团队协作功能
- 500+ 模型按需切换，延迟、成本、推理深度随时匹配

## 与其他 AI 编程工具的区别

| 特性 | Kilo Code | 其他工具 |
|------|-----------|----------|
| 平台覆盖 | IDE + CLI + Mobile + Slack + Cloud | 以 IDE 为主 |
| 会话同步 | 全平台同步 | 不跨平台 |
| 模型数量 | 500+ 模型、零加价、自动路由 | 通常几十种 |
| 团队功能 | 内建协作、用量追踪 | 有限/额外配置 |
| 部署能力 | 内建部署功能 | 需要外部工具 |
| 自动化 | 代码审查、自动修复 PR | 基本自动化 |

## 开放源代码

## 使用成本

| 方式 | 说明 |
|------|------|
| **BYOK** | 自带 API Key，只付模型提供商的原始价格，零加价 |
| **免费额度** | 注册即送 $20 免费积分（可用于 Gemini 2.5 Pro、Claude 4 Sonnet/Opus、GPT-4.1 等） |
| **Kilo Auto** | 免费模型档位，无需信用卡即可使用 |
| **Kilo Pass** | 可选订阅：Pro $19/月、Expert $199/月，解锁更多功能 |

## KiloClaw

Kilo 还提供 **KiloClaw** 托管服务——部署、管理和连接 AI 代理到聊天平台、开发工具和触发器，无需自托管。

## 一句话总结

> 如果你想要**模型自由（500+ 零加价）、多平台覆盖、内建协作与自动化**，Kilo Code 是目前开源 AI 编码助手里选项最全的一个。
