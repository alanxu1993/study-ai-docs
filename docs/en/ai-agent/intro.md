# 一、AI Agent 简介

## 什么是 AI Agent？

AI Agent（智能体）是一个能像 **数字员工** 一样**接任务、拆步骤、执行动作**的自动化实体。只要任务可拆解为操作流程，就能被 AI Agent 接管。

![幽灵在工位上接任务、拆步骤、沿传送带执行](/images/ai-agent/intro/01-digital-employee.png)

### 核心公式

```
Agent = LLM (大脑) + Planning (规划) + Tool use (执行) + Memory (记忆)
```

| 模块 | 角色 | 说明 |
|------|------|------|
| **LLM (大脑)** | 推理引擎 | 负责理解意图、生成文本和进行逻辑判断 |
| **Planning (规划)** | 任务指挥官 | 将复杂目标拆解成可执行的步骤 |
| **Memory (记忆)** | 经验笔记本 | 记录对话历史（短期）和存储专业知识库（长期） |
| **Tool Use (工具)** | 灵活的双手 | 调用搜索、数据库、代码执行等外部工具 |

## Agent 与传统 AI 模型的区别

![左边一次问答就结束，右边接上工具转着圈干活](/images/ai-agent/intro/03-traditional-vs-agent.png)

| 维度 | 传统 AI 模型 | AI Agent |
|------|-------------|----------|
| **交互方式** | 单次输入输出 | 多轮对话、持续交互 |
| **决策能力** | 基于输入直接推理 | 规划、反思、迭代优化 |
| **工具使用** | 无法主动调用外部工具 | 可调用搜索、计算器、API 等 |
| **记忆机制** | 仅限当前上下文 | 短期 + 长期记忆 |
| **目标导向** | 完成单一预测任务 | 完成复杂目标 |
| **错误处理** | 输出即结束 | 可自我纠错、重试 |

一句话总结：**传统 AI 是"问答机"，Agent 是"干活的"**。同样的模型能力，一旦装上规划、工具和记忆，就从"被动的回答"变成了"主动地完成任务"。

## 核心模式：从 Prompt 到 Reasoning Loop

普通的 LLM 只是 **One-shot（一次性）** 的响应，而 Agent 的核心在于 **Iterative（迭代）**。

![幽灵在思考-行动-观察的三角形跑道上反复跑圈逼近答案](/images/ai-agent/intro/02-reaction-loop.png)

### ReAct 模式 (Reason + Act)

这是目前最主流的 Agent 推理逻辑：

```
1. Thought (思考) → 模型描述要做什么，为什么要这么做
2. Action (行动) → 模型选择一个工具（如：Google Search）
3. Observation (观察) → 模型读取工具返回的结果
4. Repeat (循环) → 重复上述步骤，直到得出最终答案
```

```
┌─────────┐    ┌─────────┐    ┌─────────────┐
│ Thought  │───▶│ Action  │───▶│ Observation │
│   思考   │    │   行动    │    │    观察     │
└─────────┘    └─────────┘    └─────────────┘
      ▲                              │
      └──────────── 循环 ────────────┘
```

### 实际案例

用户问："分析公司上季度的销售数据"

| 循环 | Thought | Action | Observation |
|------|---------|--------|-------------|
| 1 | 需要先连接数据库 | 调用数据库工具 | 连接成功 |
| 2 | 提取 Q3 数据 | 执行 SQL 查询 | 返回 5000 条记录 |
| 3 | 按产品和地区分类 | 数据处理 | 分为 10 个产品 × 5 个地区 |
| 4 | 计算环比增长率 | 数据计算 | 增长率 15% |
| 5 | 生成可视化图表 | 调用图表工具 | 生成柱状图 |
| ✅ | 汇总结果返回用户 | — | — |

::: info ReAct 模式的精髓
Agent 不是一次性给出答案，而是在**思考 → 行动 → 观察**的循环中逐步逼近目标。每次观察都可以调整下一步行动。
:::
