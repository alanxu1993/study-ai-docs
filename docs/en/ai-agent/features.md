# 三、核心特征

一个合格的 AI Agent 通常具备以下五大核心特征：

## 3.1 自主性（Autonomy）

> 无需人类逐步指导，能够独立运作

- 自己决定下一步该做什么
- 在权限范围内自主执行任务
- **示例**：你说"帮我订明天去上海的机票"，Agent 会自动查询航班、比较价格、选择合适选项

![幽灵顺着梯子从人工操作爬到完全自主，越往上操纵杆越短](/images/ai-agent/features/01-autonomy-ladder.png)

### 自主性等级

| 等级 | 描述 | 示例 |
|------|------|------|
| L1 | 完全人工操作 | 手动搜索机票 |
| L2 | AI 建议，人工决策 | AI 推荐航班，用户选 |
| L3 | AI 执行，人工确认 | AI 选好航班，用户确认后下单 |
| L4 | AI 自主执行，异常上报 | AI 自动下单，仅异常时通知 |
| L5 | 完全自主 | 无需人工干预 |

::: warning 现实刻度
目前主流 Agent 大多停在 **L2-L3**：AI 干活、人拍板。真正的 L5 无人值守只在小范围、低风险场景里出现——因为自主性越高，越需要权限边界、审计日志和兜底护栏来托底（见"挑战与局限"一章）。
::: 

## 3.2 反应性（Reactivity）

> 能够感知环境变化并及时响应

- 根据新信息调整行为
- 对异常情况作出反应
- **示例**：订票时发现航班取消，自动寻找替代方案

## 3.3 主动性（Proactivity）

> 不仅被动响应，还能主动采取行动

- 有目标导向的行为
- 提前预判和行动
- **示例**：发现机票价格波动，主动提醒用户最佳购买时机

## 3.4 社交能力（Social Ability）

> 能与人类或其他 Agent 交互

- 理解自然语言，进行多轮对话
- 与其他 AI 系统协作
- **示例**：在订票过程中询问用户偏好（靠窗/靠走廊）

## 3.5 学习能力（Learning）

> 从历史交互中学习

- 记住用户偏好和上下文
- 持续优化行为策略
- **示例**：记住你喜欢早班飞机和靠窗座位，下次自动推荐

![幽灵身兼五职：方向盘、耳朵、望远手、握手、变厚的书](/images/ai-agent/features/02-five-traits.png)

## 五大特征关系

```
          ┌──────────────────┐
          │     自主性        │  ← 核心驱动力
          │    Autonomy       │
          └────────┬─────────┘
                   │
    ┌──────────────┼──────────────┐
    │              │              │
    ▼              ▼              ▼
┌────────┐  ┌──────────┐  ┌──────────┐
│  反应性  │  │  主动性   │  │  社交能力  │
│Reactivity│  │Proactivity│  │ Social   │
└────────┘  └──────────┘  └──────────┘
    │              │              │
    └──────────────┼──────────────┘
                   │
                   ▼
          ┌──────────────────┐
          │     学习能力       │  ← 持续进化
          │    Learning       │
          └──────────────────┘
```

::: tip 2026 现实映射
五大特征正在被"框架化"落地：自主性对应规划与权限设计，反应性对应 RAG 实时检索，主动性对应定时任务与事件监听，社交能力对应 **A2A（Agent-to-Agent）协议**，学习能力对应长期记忆与记忆评估。今天你用 LangGraph、CrewAI、AutoGen 写 Agent，本质就是在工程上拼装这五件事。
::: 

::: tip 判断 Agent 成熟度的标准
一个 Agent 越具备这五大特征（且程度越高），就越接近真正意义上的"智能体"。当前的主流 Agent 大多在 L2-L3 的自主性等级。
:::
