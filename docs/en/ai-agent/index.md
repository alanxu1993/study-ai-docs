## 关于本教程

在当今科技浪潮中，人工智能（AI）深度融入生活与工作的背后，**AI Agent（智能体）** 是支撑从对话助手到自主任务程序的核心概念。

它不是单纯的聊天工具，而是能像 **数字员工** 一样**接任务、拆步骤、执行动作**的自动化实体。

![把大脑、规划、工具、记忆四块拼成一个幽灵数字员工](/images/ai-agent/index/01-core-formula.png)

### 核心公式

```
Agent = LLM (大脑) + Planning (规划) + Tool use (执行) + Memory (记忆)
```

- **LLM（大脑）**：推理引擎，负责理解意图、生成文本、做逻辑判断
- **Planning（规划）**：把复杂目标拆成可执行步骤，还能根据结果反思调整
- **Tool use（执行）**：调用搜索、数据库、代码执行等外部工具，把"想"变成"做"
- **Memory（记忆）**：短期记忆记录当前对话，长期记忆跨会话复用知识

::: tip 为什么现在值得学？
2025 年全球智能体市场规模已突破 **680 亿美元**，预计 2026 年跨过千亿美元门槛；DeepSeek-R1、Manus、Operator 等产品先后登场，Agent 正从"Demo 演示"走向"企业生产力"。这个公式就是看懂这一切的钥匙。
:::
