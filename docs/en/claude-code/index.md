# Claude Code 完整教程

> 来源：[小林学AI](https://xiaolinxueai.com/claudecode/) — Claude Code 从入门到精通

## 教程简介

**Claude Code** 是 Anthropic 推出的终端原生 AI 编程助手。无需 IDE 插件，直接在终端中运行，支持任务驱动、文件操作、命令执行、Git 管理等全流程开发能力。支持官方模型和国产大模型（DeepSeek、智谱GLM、阿里百炼等）。

本教程共 16 篇，涵盖从安装上手到进阶配置的完整内容。
