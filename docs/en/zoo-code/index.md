# Zoo Code 快速上手

Zoo Code 是一款开源 AI 编程助手，以 VS Code 扩展方式集成。它的定位是"你的 AI 开发团队，就在编辑器里"。

Zoo Code 源于 Roo Code，在原项目停止活跃开发后，由社区核心贡献者接手继续维护和迭代。

**最新版本**：v3.76.0 | **许可证**：Apache 2.0 | **GitHub**：⭐ 1.5k+（[Zoo-Code-Org/Zoo-Code](https://github.com/Zoo-Code-Org/Zoo-Code)）

---

## 核心能力

| 能力 | 说明 |
|------|------|
| 代码生成 | 从自然语言描述生成代码 |
| 重构与调试 | 对现有代码重构和 Debug |
| 文档编写 | 编写和更新项目文档 |
| 代码问答 | 回答关于代码库的问题 |
| 任务自动化 | 自动化重复性编程任务 |
| MCP 集成 | 支持 Model Context Protocol 服务器扩展 |
