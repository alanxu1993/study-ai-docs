# 四、Zoo Code 核心特性详解

## Semble 代码库智能

Semble 是 Zoo Code 的语义代码搜索系统，优势在于：

- **快速按需搜索**：无需预先构建索引，即开即用
- **语义理解**：不仅匹配关键词，更能理解代码含义
- **自动设置**：无需手动配置索引流程

## 增强的 Orchestrator 工作流

Orchestrator 是 Zoo Code 的任务编排系统：

| 特性 | 说明 |
|------|------|
| 安全任务委派 | 子任务与父任务之间有严格权限隔离 |
| 并行任务协调 | 多个子任务可同时执行，互不干扰 |
| 父子任务恢复 | 某项任务失败时，可自动恢复或回滚 |
| Provider 配置隔离 | 子任务可使用不同的 AI 模型 |

子代理各自拥有独立的上下文窗口，父代理只接收执行摘要，因此可以承接远超单一上下文限制的大型任务。

## DCG — 破坏性命令防护

Destructive Command Guard（DCG）是 v3.76.0 引入的关键安全特性：

- **自动拦截危险命令**：如 `rm -rf`、`git push --force`、数据库删除等
- **白名单信任机制**：可信工作流中的命令无需反复审批
- **长时间自主运行**：减少了手动点击审批按钮的频率，支持更长的无人值守任务
- **托管二进制安全**：下载和安装第三方二进制文件经过安全加固

## 差异编辑（Diff-based Editing）

Zoo Code 采用与 Git diff 类似的差异编辑机制：

- **只改该改的**：仅重写发生变化的代码行，而不是整个文件
- **变更可审查**：每次修改清晰展示，方便人工确认
- **节省 Token**：相比整文件重写，显著降低 API 成本
- **配合检查点**：所有变更可用检查点（Checkpoint）追踪，随时一键撤销

## 智能批处理

Zoo Code 会对工具审批请求进行智能分组：

- 相关工具操作合并为一次审批
- 不相关的请求保持独立，避免混淆
- 提升大规模操作的执行效率

## 终端执行

Zoo Code 直接在 VS Code 集成终端中执行命令并实时读取输出：

- 安装依赖、运行测试、执行脚本、部署应用
- 修复了旧版"终端命令过早结束"的问题——现在会等待命令真正完成再进入下一步
- 对长时间运行的进程（如 dev server）持续观察输出，捕获编译错误和崩溃

## MCP 集成

通过 Model Context Protocol 扩展能力，连接数据库、外部 API、云端服务等：

- **内置 MCP 配置**：在设置中直接添加/管理 MCP 服务器
- **按模式限制 MCP**：不同工作模式下使用不同的 MCP 服务器集合
- **注意**：MCP 工具会显著消耗上下文，只启用实际用到的服务器

## 工作区控制

| 控制项 | 说明 |
|--------|------|
| 规则管理 | 定义项目级别的行为规则和约束 |
| 按模式限制 MCP | 不同模式下使用不同的 MCP 服务器 |
| 多根路径控制 | 限定 Zoo Code 可操作的文件范围 |
| 模型推理选项 | 按模式调整模型的推理参数 |
| 变更审查 | 完成后查看和审查所有变更 |
| 提供商档案 | 多套模型配置一键切换 |

## 可靠性改进

- 任务状态竞态修复，避免并行任务状态混乱
- 上下文管理优化，长对话更稳定
- 遥测与模型缓存获取在失败和并发下更健壮
