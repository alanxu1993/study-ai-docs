# 四、Kilo Code 核心功能

## 智能编码（Agentic Coding）

- 从自然语言生成跨多文件的代码
- **自我检查（Self-checking）**：Agent 会运行测试、终端命令验证自己的工作，发现错误自动修复（如自动安装缺失依赖、重跑构建）
- 自动重构和重复任务自动化
- 任务完成发送**系统通知**

## Autocomplete（自动补全）

在你输入时提供内联代码建议：

- 实时代码预测（ghost text 幽灵文本，Tab 接受）
- 上下文感知的建议
- 多行补全支持
- 基于 Codestral FIM 等模型

## Code Actions（代码操作）

AI 驱动的重构和修复：

- 一键重构选定代码
- 自动修复常见问题
- 代码优化建议
- 智能命名建议

## Task & Todo Lists（任务与待办）

将复杂任务拆解为可管理的步骤：

- Agent 自动生成子任务
- 追踪每个子任务的完成状态
- 可视化任务进度
- 支持任务修改和调整

## Plan Mode 与计划文件

- 规划阶段自动生成实施计划
- 可把方案导出为 `.md` 计划文件到 `/plans/` 目录
- 确认计划后再进入执行，避免盲目改动

## Checkpoints（检查点）

保存和恢复工作状态：

- 在关键节点保存快照
- 出错时回滚到安全的检查点
- 支持多个检查点管理
- 比较检查点间的差异

## Browser Use（浏览器自动化）

Kilo 的突出能力——可以启动并自动操作浏览器：

- 实时验证前端 UI 改动
- 调试前端组件
- 自动填写表单、抓取网页数据
- 测试 Web 应用

结合终端控制，Kilo 把"写代码 → 跑终端 → 验浏览器"整合成单一循环，免去了反复切换上下文的损耗。

## Enhance Prompt（提示增强）

自动改进你的提示词：

- 分析模糊的描述并补全细节
- 添加必要的上下文和约束
- 优化任务表述的结构
- 提高 Agent 理解的准确度

## Git Commit Generation

AI 生成提交信息：

- 分析代码变更自动生成 commit message
- 遵循常见的提交规范（如 Conventional Commits）
- 可手动编辑和调整

## MCP 集成

- **MCP 市场**：查找、安装、使用社区 MCP 服务器，一键扩展能力
- **MCP 配置 UI**：增删改服务器、重启、按服务器设置超时、查看工具/资源/日志/认证
- **工具白名单**：允许列（allowlist）控制哪些工具可用

## 平台集成

| 集成平台 | 能力 |
|----------|------|
| VS Code | 完整 IDE 集成 |
| JetBrains | IntelliJ/PyCharm/WebStorm 等 |
| CLI | 终端脚本和自动化 |
| Cloud Agent | 浏览器云端运行，无需本地机器 |
| Mobile | iOS 和 Android |
| Slack | 工作区对话 |

## 自动化与 CI/CD

- **Autonomous Mode**：`kilo run --auto "运行测试并修复失败"` 全自动执行，适合 CI/CD（注意：`--auto` 会关闭所有权限确认，仅在可信环境使用）
- 自动 AI 代码审查：在 PR 上设置自动化代码审查
- 自动修复 PR、基于 Issue 创建 PR

## 协作功能

- 会话共享：与团队成员分享编码会话
- 团队管理：配置团队成员权限
- 用量追踪：监控团队的 AI 使用情况
- 企业部署：企业级安全和控制（SSO、审计日志等）

## 部署与安全

- 直接部署应用
- 运行安全扫描
